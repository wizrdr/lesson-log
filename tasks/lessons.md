## 2026-09-05 — облачные мутации Supabase агент не выполняет
Классификатор auto-режима блокирует `supabase link`, `db push`, PATCH management API и даже запись shell-скрипта с этими командами. Не тратить попытки: сразу отдавать Максиму готовую команду для `! ...`, а агентам оставлять миграции, функции и тесты.

## 2026-09-05 — общий Supabase-проект на два репо
`supabase db push` (даже с `--include-all`) требует, чтобы все удалённые версии миграций были в локальной папке — при двух репо это невозможно. Рабочий путь: `npx supabase db query --linked -f <file>` + `npx supabase migration repair --linked --status applied <version>` (обёрнуто в `scripts/db-migrate.sh`). Правила разрешений в `~/.claude/settings.json` агент править не может — только пользователь.
